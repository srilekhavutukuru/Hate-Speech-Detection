# Hate-Speech-Detection

## Overview

This project is a simple Hate Speech Detection system developed using Python. The main objective of the project is to classify text messages as either Hate Speech or Non-Hate Speech.

In this project, basic data analysis and visualization techniques were used to understand the dataset and classify the text.

### Features
Detects hate speech in text messages\
Data analysis using Pandas and NumPy\
Data visualization using Matplotlib and Seaborn\
Basic classification model implementation
## Technologies Used
Python\
NumPy\
Pandas\
Matplotlib\
Seaborn\
Scikit-learn\
Dataset

The dataset contains text data labeled as:

Hate Speech\
Non-Hate Speech
## Project Workflow
1. Data Loading
Loaded the dataset using Pandas
2. Data Analysis
Explored and analyzed the dataset
Checked the distribution of hate and non-hate messages
3. Data Visualization
Generated graphs using Matplotlib and Seaborn
4. Classification
Classified text messages as Hate Speech or Non-Hate Speech using a classification model
